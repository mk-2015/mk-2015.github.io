2. Bit-Level 6-Bit Packing Inspector

Base64 groups every 3 input bytes (24 bits) into four 6-bit indices (0–63). When input bytes are not a multiple of 3, trailing zero bits are appended to fill the final 6-bit group and = padding characters are added (unless padding is disabled).
