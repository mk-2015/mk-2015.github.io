Project InterLib

InterLib (or the internet library) is an independent website built on $0 budget to conserve public-domain data, books, tools, and games.

InterLib also hosts a mirror of man-pages for preinstalled packages in the latest version of Ubuntu, generated via GitHub Actions.

Help Project InterLib by adding public-domain books to the Books Repository. See Legal for details.

If you have any suggestions or issues, please open an issue at The ghpages Repo.
