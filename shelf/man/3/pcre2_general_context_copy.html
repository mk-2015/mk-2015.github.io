PCRE2_GENE...NTEXT_COPY(3) Library Functions Manual PCRE2_GENE...NTEXT_COPY(3)

NAME
       PCRE2 - Perl-compatible regular expressions (revised API)

SYNOPSIS

       #include <pcre2.h>

       pcre2_general_context *pcre2_general_context_copy(
         pcre2_general_context *gcontext);

DESCRIPTION

       This  function  makes a new copy of a general context, using the memory
       allocation functions in the context, if set, to get the necessary  mem‐
       ory.  Otherwise malloc() is used. The result is NULL if the memory can‐
       not be obtained.

       There is a complete description of the PCRE2 native API in the pcre2api
       page and a description of the POSIX API in the pcre2posix page.
