NAME
       URI::icaps - URI scheme for ICAPS Identifiers

VERSION
       Version 5.20

SYNOPSIS
           use URI::icaps;

           my $uri = URI->new('icaps://icap-proxy.example.com/');

DESCRIPTION
       This module implements the "icaps:" URI scheme defined in RFC 3507
       <http://tools.ietf.org/html/rfc3507>, for the Internet Content
       Adaptation Protocol
       <https://en.wikipedia.org/wiki/Internet_Content_Adaptation_Protocol>.

SUBROUTINES/METHODS
       This module inherits the behaviour of URI::icap and overrides the
       securesecure> method.

   secure
       returns 1 as icaps is a secure protocol
