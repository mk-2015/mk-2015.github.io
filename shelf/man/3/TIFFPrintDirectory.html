NAME
       TIFFPrintDirectory - print a description of a TIFF directory

SYNOPSIS
          #include <tiffio.h>

       void TIFFPrintDirectory(TIFF *tif, FILE *fd, long flags)

DESCRIPTION
       TIFFPrintDirectory()  prints  a description of the current directory in
       the specified TIFF file to the standard  I/O  output  stream  fd.   The
       flags parameter is used to control the "level of detail" of the printed
       information;  it  is a bitwise-or of the flags defined in tiffio.h: box
       center; l|l|l.  T{ Name T}   T{ Value T}   T{ Description T} _ T{ TIFF‐
       PRINT_NONE T}   T{ 0x0 T}   T{ no extra info T} _  T{  TIFFPRINT_STRIPS
       T}   T{  0x1 T}   T{ strips/tiles info T} _ T{ TIFFPRINT_CURVES T}   T{
       0x2 T}   T{ color/gray  response  curves  T}  _  T{  TIFFPRINT_COLORMAP
       T}   T{  0x4  T}   T{  colormap  T}  _ T{ TIFFPRINT_JPEGQTABLES T}   T{
       0x100 T}   T{ JPEG Q matrices T} _  T{  TIFFPRINT_JPEGACTABLES  T}   T{
       0x200  T}   T{  JPEG  AC  tables T} _ T{ TIFFPRINT_JPEGDCTABLES T}   T{
       0x200 T}   T{ JPEG DC tables T}

NOTES
       In C++ the flags parameter defaults to 0.

RETURN VALUES
       None.

DIAGNOSTICS
       None.
