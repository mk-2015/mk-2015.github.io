NAME
       Dpkg::Control::Changelog - represent info fields output by
       dpkg-parsechangelog

DESCRIPTION
       This class derives directly from Dpkg::Control with the type
       CTRL_CHANGELOG.

METHODS
       $c = Dpkg::Control::Changelog->new()
           Create a new empty set of changelog related fields.
