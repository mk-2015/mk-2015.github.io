NAME
       setlogcons - Send kernel messages to console N

SYNOPSIS
       setlogcons [options] [N]


DESCRIPTION
       The command setlogcons N sets all kernel messages to the console speci‐
       fied as N.

       By default kernel messages are sent to the current console.

       To change the level of messages sent, use dmesg


OPTIONS
       -C, --console=DEV
              the console device to be used.

       -V, --version
              print version number.

       -h, --help
              print this usage message.
