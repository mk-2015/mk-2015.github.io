NAME
       lvmsar — LVM system activity reporter

SYNOPSIS
       lvmsar

DESCRIPTION
       lvmsar is not supported under LVM2. The device-mapper statistics facil‐
       ity provides similar performance metrics using the dmstats(8) command.

SEE ALSO
       dmstats(8), lvm(8)
