Name
       shadowconfig - turn shadow passwords on

Synopsis
       shadowconfig

Description
       shadowconfig on will turn shadow passwords on.

Errors
       shadowconfig  will  print an error message and exit with a nonzero code
       if it finds anything awry.  If that happens, you should correct the er‐
       ror and run it again.  Turning shadow passwords on when  they  are  al‐
       ready on is harmless.

Caveats
       Turning  shadow  passwords off using shadowconfig is not supported any‐
       more.

See also
       Read /usr/share/doc/passwd/README.Debian for a  brief  introduction  to
       shadow passwords and related features.
