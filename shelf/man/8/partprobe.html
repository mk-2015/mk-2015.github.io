NAME
       partprobe - inform the OS of partition table changes

SYNOPSIS
       partprobe [-d] [-s] [devices...]

DESCRIPTION
       This manual page documents briefly the partprobe command.

       partprobe is a program that informs the operating system kernel of par‐
       tition table changes.

OPTIONS
       This program uses short UNIX style options.

       -d, --dry-run
              Don't update the kernel.

       -s, --summary
              Show a summary of devices and their partitions.

       -h, --help
              Show summary of options.

       -v, --version
              Show version of program.
