The  utility  can  be  used to edit property lists, to verify the
syntax, or to convert from one format to another. If is given  as
the  file path, stdin and stdout are used.  The first part is the
action to perform, one of: Print the whole plist  to  stdout,  in
the  human-readable  GNUStep  format.   Verifies the plist can be
parsed.  Converts the plist to another format.  can  be  one  of:
Apple  XML.   Apple  binary.   OpenStep (untyped human-readable).
GNUStep (typed  human-readable).   JSON  (lossy  human-readable).
The NSPropertyListFormat names are accepted too.  The default ac‐
tion  is  The general options are: The plutil "keypath" is a dot-
separated chain of keys for traversing a plist object.  An  empty
keypath  refers  to the object itself. The format of keys conform
to that of GNUStep plist string literals.  Quoted strings in  the
keypath  is  a GNUStep extension.  The Objective-C and Swift lit‐
eral output formats are not yet implemented.  This version of was
written by first appeared in Mac OS X 10.2. It received  path-re‐
lated capabilities around Mac OS X 10.13.
