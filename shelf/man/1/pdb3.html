NAME
       pdb3.13 - the Python debugger

SYNOPSIS
       pdb3.13 script [...]

DESCRIPTION
       See  the  chapter "The Python Debugger" in the Python Library Reference
       for more information on the use of pdb.  When the debugger is  started,
       help is available via the help command.

SEE ALSO
       python3.13(1). Chapter "The Python Debugger" of the Python Library Ref‐
       erence.     Available     in     the    python3.13-doc    package    at
       /usr/share/doc/python3.13/html/library/pdb.html.
