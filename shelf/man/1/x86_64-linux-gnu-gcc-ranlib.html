NAME
       gcc-ranlib - a wrapper around ranlib adding the --plugin option


SYNOPSIS
       gcc-ranlib [OPTION] ... [ARGS...]


DESCRIPTION
       gcc-ranlib  is a wrapper around ranlib(1) adding the appropriate --plu‐
       gin option for the GCC 14 compiler.


OPTIONS
       See ranlib(1) for a list of options that nm understands.


SEE ALSO
       ranlib(1)
