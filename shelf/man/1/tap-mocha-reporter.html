NAME
       tap-mocha-reporter - format output of tap using mocha like reporter

SYNOPSIS
       tap-mocha-reporter { --help | reporter }

DESCRIPTION
       Reads  TAP data on stdin, and formats to stdout using the specified re‐
       porter. (Note that some reporters write to files instead of stdout.)

OPTIONS
