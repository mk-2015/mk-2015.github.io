NAME
       pgmslice - extract one line of pixel values out of a PGM


DESCRIPTION
       This program is part of Netpbm(1).

       Starting  with  Netpbm 10.3, pgmslice is obsolete.  Use pamslice(1) in‐
       stead.  It is backward compatible.
