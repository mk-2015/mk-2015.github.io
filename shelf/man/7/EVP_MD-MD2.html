NAME
       EVP_MD-MD2 - The MD2 EVP_MD implementation

DESCRIPTION
       Support for computing MD2 digests through the EVP_MD API.

   Identity
       This implementation is only available with the legacy provider, and is
       identified with the name "MD2".

   Gettable Parameters
       This implementation supports the common gettable parameters described
       in EVP_MD-common(7).

       provider-digest(7), OSSL_PROVIDER-default(7)
