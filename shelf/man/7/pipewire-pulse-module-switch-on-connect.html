NAME
       pipewire-pulse-module-switch-on-connect - Switch on Connect

MODULE NAME
       module-switch-on-connect

MODULE OPTIONS
       • only_from_unavailable:  boolean,  only  switch from unavailable ports
         (not implemented yet)

       • ignore_virtual:  boolean,  ignore  new  virtual  sinks  and  sources,
         defaults to true

       • blocklist: regex, ignore matching devices, default=hdmi
