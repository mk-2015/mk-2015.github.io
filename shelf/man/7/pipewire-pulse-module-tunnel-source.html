NAME
       pipewire-pulse-module-tunnel-source - Tunnel Source

MODULE NAME
       module-tunnel-source

MODULE OPTIONS
       • server: address

       • source: name of the remote source

       • source_name: name for the local source

       • source_properties: properties for the local source

       • reconnect_interval_ms:  interval  to  try reconnects, 0 or omitted if
         disabled

       • format: sample format

       • channels: number of channels

       • rate: sample rate

       • channel_map: channel map

       • latency_msec: fixed latency in ms

       • cookie: cookie file path

SEE ALSO
       libpipewire-module-pulse-tunnel
