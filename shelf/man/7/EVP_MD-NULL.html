NAME
       EVP_MD-NULL - The NULL EVP_MD implementation

DESCRIPTION
       Support for a NULL digest through the EVP_MD API.  This algorithm does
       nothing and returns 1 for its init, update and final methods.

   Algorithm Name
       The following algorithm is available in the default provider:

       "NULL"

   Gettable Parameters
       This  implementation  supports the common gettable parameters described
       in EVP_MD-common(7).

SEE ALSO
       EVP_MD_CTX_set_params(3), provider-digest(7), OSSL_PROVIDER-default(7)
