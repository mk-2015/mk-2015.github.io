1. Virtual Memory vs. Heap Syscalls

A C program does not get raw physical RAM addresses from malloc(3). It receives virtual addresses mapped in its own process page tables by the operating system kernel.

User-space allocators (such as glibc ptmalloc2, jemalloc, mimalloc, or musl) sit between your application and the kernel. They request larger memory regions from the OS and carve them into smaller blocks so calls to malloc() and free() rarely need a system call.

Mechanism Syscall / Interface How It Behaves Typical Use Case
Program Break brk(2) / sbrk(2) Moves the contiguous end of the data/heap segment up or down in one linear region. Small and medium allocations in traditional UNIX heaps (can pin memory if top chunk stays high).
Anonymous Mapping mmap(2) / munmap(2) Maps independent page-aligned virtual memory regions (usually multiples of 4096 bytes) anywhere in address space. Large allocations above a threshold, thread arenas, and returning pages back to the OS cleanly.

2. Chunk Layout, Headers, and Alignment

When you ask for malloc(n), the allocator usually allocates slightly more than n bytes. Immediately before the pointer returned to your code is a metadata header storing the chunk size and state flags.

Most architectures require returned pointers to be aligned (commonly 8 bytes on 32-bit and 16 bytes on 64-bit) so types like long double, SIMD vectors, or structs with strict alignment faults do not trigger alignment traps or unaligned-access penalties.

Allocated chunk in memory:

  +-----------------------------------+  <-- chunk base (aligned)
  | size_and_flags (e.g. size | PREV_INUSE) |
  +-----------------------------------+  <-- user pointer returned by malloc()
  |                                   |
  |        Payload (user bytes)       |
  |                                   |
  +-----------------------------------+  <-- next chunk starts here

Free chunk (when not adjacent to an in-use chunk, may also store links):

  +-----------------------------------+
  | size_and_flags                    |
  +-----------------------------------+
  | next_free *                       |
  +-----------------------------------+
  | prev_free *                       |
  +-----------------------------------+
  | unused free space ...             |
  +-----------------------------------+

Because valid chunk sizes on a 16-byte-aligned allocator are multiples of 16, the lowest bits (such as bit 0, bit 1, bit 2) are always zero in an unmasked size value. Allocators pack status flags into those low bits:

  • PREV_INUSE` (bit 0 = 1): The immediately preceding physical chunk in memory is currently allocated. Prevents coalescing backward into live data and lets the previous chunk omit its trailing footer while in use.
  • IS_MMAPPED` (bit 1 = 2): This block came directly from mmap(2) rather than the main heap arena, so free() unmaps it with munmap(2).
  • NON_MAIN_ARENA` (bit 2 = 4): Belongs to a non-main thread arena rather than the primary heap.

3. Allocation Strategies, Splitting, and Coalescing

When free(ptr) is called, memory is rarely handed straight back to the kernel. Instead, the chunk is marked free and linked into a free list (or bin) for future reuse.

Finding a Free Block

  • First-fit: Scans the free list and picks the first chunk large enough to satisfy the request. Fast allocation, tends to leave smaller fragments near the front of the list.
  • Best-fit: Searches for the smallest free chunk that still fits the request. Reduces wasted space per allocation, but scanning a long list takes more CPU time and can leave tiny, unusable "splinter" chunks.
  • Next-fit: Resumes scanning from where the previous search stopped, spreading allocations more evenly across the heap.

Splitting and Coalescing

  • Splitting: If a free chunk is larger than the requested payload plus header overhead (and large enough to hold a valid minimum-sized free chunk), the allocator carves off the needed portion and leaves the remainder as a smaller free chunk.
  • Coalescing (merging): If the physical chunk right after or right before a freed chunk is also free, the allocator merges them into one contiguous free chunk. Without coalescing, thousands of small malloc() and free() cycles leave fragmented holes that cannot satisfy a larger request even when total free bytes are plenty.

4. Arenas, Tcaches, and Fragmentation

A single global heap protected by one mutex creates lock contention when multiple threads allocate and free memory concurrently. Production allocators solve this with layered fast paths:

  • Per-thread caches (`tcache` / thread-local caches): Keep small recently freed blocks per thread so common allocations happen with little or no lock contention.
  • Arenas / segregated bins: Group chunks by size class (small bins, large bins, fastbins) so lookups are fast and similarly sized objects stay grouped together.
  • Internal vs. external fragmentation: Internal fragmentation is wasted space inside an allocated block (alignment padding or rounding up to a size class). External fragmentation is free memory scattered across the heap in chunks that are too small or non-contiguous for a needed allocation size.

5. Complete C Allocator Implementation

The example below is a self-contained C allocator built on sbrk(2) with 16-byte alignment, header size encoding, block splitting, and forward/backward coalescing of adjacent free blocks. It is designed to show the core mechanics clearly rather than replace a production allocator.

#define _POSIX_C_SOURCE 200809L

#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

#define ALIGNMENT 16u
#define ALIGN_UP(x) (((x) + (ALIGNMENT - 1u)) & ~(size_t)(ALIGNMENT - 1u))

/* Low bit of `size` stores whether the chunk is currently allocated. */
#define FLAG_INUSE ((size_t)0x1u)
#define SIZE_MASK  (~FLAG_INUSE)

typedef struct block_hdr {
    size_t size_flags;          /* Total chunk size (including header) | FLAG_INUSE */
    struct block_hdr *prev_phys;  /* Immediately preceding physical chunk in heap */
    struct block_hdr *next_free;  /* Next node in doubly linked free list */
    struct block_hdr *prev_free;  /* Previous node in doubly linked free list */
} block_hdr_t;

#define HDR_SIZE ALIGN_UP(sizeof(block_hdr_t))
#define MIN_SPLIT_PAYLOAD ALIGN_UP(32u)

static block_hdr_t *heap_head = NULL;
static block_hdr_t *heap_tail = NULL;
static block_hdr_t *free_head = NULL;

static size_t blk_size(const block_hdr_t *b) {
    return b->size_flags & SIZE_MASK;
}

static int blk_is_free(const block_hdr_t *b) {
    return (b->size_flags & FLAG_INUSE) == 0u;
}

static void set_blk(block_hdr_t *b, size_t total_size, int inuse) {
    b->size_flags = (total_size & SIZE_MASK) | (inuse ? FLAG_INUSE : 0u);
}

static void *blk_to_payload(block_hdr_t *b) {
    return (void *)((uint8_t *)b + HDR_SIZE);
}

static block_hdr_t *payload_to_blk(void *ptr) {
    return (block_hdr_t *)((uint8_t *)ptr - HDR_SIZE);
}

static block_hdr_t *next_phys_blk(block_hdr_t *b) {
    uint8_t *cand = (uint8_t *)b + blk_size(b);
    uint8_t *end = (uint8_t *)heap_tail + blk_size(heap_tail);
    return (cand < end) ? (block_hdr_t *)cand : NULL;
}

static void freelist_remove(block_hdr_t *b) {
    if (b->prev_free) {
        b->prev_free->next_free = b->next_free;
    } else if (free_head == b) {
        free_head = b->next_free;
    }
    if (b->next_free) {
        b->next_free->prev_free = b->prev_free;
    }
    b->next_free = NULL;
    b->prev_free = NULL;
}

static void freelist_insert_front(block_hdr_t *b) {
    b->prev_free = NULL;
    b->next_free = free_head;
    if (free_head) {
        free_head->prev_free = b;
    }
    free_head = b;
}

static block_hdr_t *request_space_from_os(size_t total_needed) {
    size_t req = ALIGN_UP(total_needed);
    if (req < 4096u) {
        req = 4096u;
    }

    void *raw = sbrk((intptr_t)req);
    if (raw == (void *)-1) {
        return NULL;
    }

    block_hdr_t *b = (block_hdr_t *)raw;
    b->prev_phys = heap_tail;
    b->next_free = NULL;
    b->prev_free = NULL;
    set_blk(b, req, 0);

    if (!heap_head) {
        heap_head = b;
    }
    heap_tail = b;

    /* Coalesce with previous physical block if that block is already free. */
    if (b->prev_phys && blk_is_free(b->prev_phys)) {
        block_hdr_t *prev = b->prev_phys;
        size_t merged = blk_size(prev) + blk_size(b);
        set_blk(prev, merged, 0);
        heap_tail = prev;
        b = prev;
    } else {
        freelist_insert_front(b);
    }

    return b;
}

static void split_block(block_hdr_t *b, size_t needed_total) {
    size_t current = blk_size(b);
    if (current < needed_total + HDR_SIZE + MIN_SPLIT_PAYLOAD) {
        return;
    }

    size_t rem_size = current - needed_total;
    set_blk(b, needed_total, 1);

    block_hdr_t *rem = (block_hdr_t *)((uint8_t *)b + needed_total);
    rem->prev_phys = b;
    rem->next_free = NULL;
    rem->prev_free = NULL;
    set_blk(rem, rem_size, 0);

    block_hdr_t *after = next_phys_blk(rem);
    if (after) {
        after->prev_phys = rem;
    } else {
        heap_tail = rem;
    }

    freelist_insert_front(rem);
}

void *tiny_malloc(size_t size) {
    if (size == 0) {
        return NULL;
    }

    size_t payload = ALIGN_UP(size);
    size_t needed_total = HDR_SIZE + payload;

    block_hdr_t *curr = free_head;
    while (curr) {
        if (blk_size(curr) >= needed_total) {
            freelist_remove(curr);
            split_block(curr, needed_total);
            set_blk(curr, blk_size(curr), 1);
            return blk_to_payload(curr);
        }
        curr = curr->next_free;
    }

    curr = request_space_from_os(needed_total);
    if (!curr) {
        return NULL;
    }

    freelist_remove(curr);
    split_block(curr, needed_total);
    set_blk(curr, blk_size(curr), 1);
    return blk_to_payload(curr);
}

void tiny_free(void *ptr) {
    if (!ptr) {
        return;
    }

    block_hdr_t *b = payload_to_blk(ptr);
    if (blk_is_free(b)) {
        return;
    }

    set_blk(b, blk_size(b), 0);

    /* Coalesce with next physical block if free. */
    block_hdr_t *nxt = next_phys_blk(b);
    if (nxt && blk_is_free(nxt)) {
        freelist_remove(nxt);
        size_t merged = blk_size(b) + blk_size(nxt);
        set_blk(b, merged, 0);

        block_hdr_t *after_nxt = next_phys_blk(b);
        if (after_nxt) {
            after_nxt->prev_phys = b;
        } else {
            heap_tail = b;
        }
    }

    /* Coalesce with previous physical block if free. */
    block_hdr_t *prv = b->prev_phys;
    if (prv && blk_is_free(prv)) {
        freelist_remove(prv);
        size_t merged = blk_size(prv) + blk_size(b);
        set_blk(prv, merged, 0);

        block_hdr_t *after_b = next_phys_blk(b);
        if (after_b) {
            after_b->prev_phys = prv;
        } else {
            heap_tail = prv;
        }
        b = prv;
    }

    freelist_insert_front(b);
}

int main(void) {
    char *a = tiny_malloc(64);
    char *b = tiny_malloc(128);
    char *c = tiny_malloc(64);

    if (!a || !b || !c) {
        return 1;
    }

    strcpy(a, "first block");
    strcpy(b, "second block");
    strcpy(c, "third block");

    tiny_free(b);
    tiny_free(a); /* Coalesces with freed `b` right after it */

    char *d = tiny_malloc(160);
    if (d) {
        strcpy(d, "reused coalesced region");
        printf("d = %s, c = %s\n", d, c);
    }

    tiny_free(d);
    tiny_free(c);
    return 0;
}

6. Common Heap Bugs

  • Use-after-free (UAF): Reading or writing through a pointer after free(). The memory may already be reallocated to another structure or hold allocator free-list pointers, causing silent data corruption or crashes.
  • Double free: Calling free(p) twice on the same pointer without reassigning p = NULL. Corrupts free-list pointers and can let the same memory block be handed out twice.
  • Heap buffer overflow: Writing past the requested byte count overwrites adjacent chunk headers or neighboring allocations, corrupting sizes, flags, or pointers.
  • Invalid / non-heap pointer passed to free(): Calling free() on stack variables, static globals, string literals, or interior pointers causes undefined behavior and immediate crashes.
  • Memory leaks: Retaining pointers or dropping references without calling free() grows heap usage until the process hits memory limits or the OOM killer terminates it.
