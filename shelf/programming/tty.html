What is a TTY in Linux/Unix?

1. What does TTY stand for?

TTY stands for Teletypewriter. Originally, these were physical electromechanical typewriters wired to mainframes that printed output on paper. Today in Linux and Unix, a TTY is a kernel subsystem that handles text input/output, line discipline (like echoing keys, handling Backspace, and turning Ctrl+C into SIGINT), and terminal sessions.

2. How a TTY Connects to Your Shell

Terminal Pipeline 
[ Keyboard / Screen ]  (or Terminal Emulator / SSH)
         |
         v
+-------------------+

|  TTY Line         |  <-- Handles echo, Ctrl+C (SIGINT), line buffering
|  Discipline       |
+-------------------+
         |
         v
[ stdin / stdout / stderr ]  (File Descriptors 0, 1, 2)
         |
         v
[ Shell (bash, zsh, sh) ]

3. Common TTY Device Files in /dev

/dev/tty1 – /dev/tty63 (Virtual Consoles)
Built-in kernel text consoles. You can switch between them on Linux using Ctrl + Alt + F1 through F6.
/dev/pts/0, /dev/pts/1... (Pseudo-Terminals / PTY)
Software-emulated terminals created whenever you open a terminal app in a GUI (like Konsole or GNOME Terminal) or connect over ssh.
/dev/ttyS0 (Serial Console)
Hardware UART serial ports, commonly used on embedded boards, routers, and QEMU virtual machines.
/dev/console (System Console)
The primary kernel log and emergency boot console used by PID 1 (init) during startup.
/dev/tty (Current Controlling Terminal)
A special alias pointing to whatever terminal the current process is attached to.

4. Check Your TTY in C (ttyname.c)

ttyname.c 
#include <stdio.h>
#include <unistd.h>

int main(void) {
  if (isatty(STDIN_FILENO)) {
    printf("Connected to TTY: %s\n", ttyname(STDIN_FILENO));
  } else {
    printf("Not connected to a terminal (piped or redirected).\n");
  }
  return 0;
}
