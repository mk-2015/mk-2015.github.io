How to write a unix shell in c

Full source code

shell.c 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/wait.h>

#define MAX_LINE 1024
#define MAX_ARGS 64
#define DELIMITERS " \t\r\n\a"

void parse_input(char *line, char **args) {
  int i = 0;
  char *token = strtok(line, DELIMITERS);

  while (token != NULL && i < MAX_ARGS - 1) {
    args[i++] = token;
    token = strtok(NULL, DELIMITERS);
  }
  args[i] = NULL;
}

int handle_builtin(char **args) {
  if (strcmp(args, "exit") == 0) {
    exit(0);
  }

  if (strcmp(args, "cd") == 0) {
    const char *target_dir = args ? args : getenv("HOME");
    if (target_dir == NULL || chdir(target_dir) != 0) {
      perror("cd");
    }
    return 1;
  }

  return 0;
}

void execute_command(char **args) {
  pid_t pid = fork();

  if (pid < 0) {
    perror("fork");
  } else if (pid == 0) {
    if (execvp(args, args) == -1) {
      perror(args);
    }
    exit(EXIT_FAILURE);
  } else {
    int status;
    waitpid(pid, &status, 0);
  }
}

int main(void) {
  char line[MAX_LINE];
  char *args[MAX_ARGS];

  while (1) {
    printf("% ");
    fflush(stdout);

    if (fgets(line, sizeof(line), stdin) == NULL) {
      printf("\n");
      break;
    }

    parse_input(line, args);

    if (args == NULL) {
      continue;
    }

    if (!handle_builtin(args)) {
      execute_command(args);
    }
  }

  return 0;
}

Questions

What is a shell?

A shell is a command-line interface that lets you interact with your operating system by typing commands.

Why do you need a shell?

On some systems you may not have a GUI, so you SSH into it and you get a shell. A shell is also used when no X Window System is present.

  • GUI: Graphical User Interface
  • CLI: Command-Line Interface
  • TUI: Terminal User Interface

BASH

BASH stands for Bourne-Again SHell, a free and open-source shell built by the GNU Project as a replacement for the original Bourne shell (sh) on traditional Unix systems. BASH is the default or most common shell on Linux and most Unix-like operating systems.
